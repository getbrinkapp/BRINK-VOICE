# BRINK icon library

The interface icons in this folder are local SVG assets from Google Material
Symbols Rounded. Primary navigation and page icons use weight 500; secondary
and action icons use weight 400. Brand marks are stored separately in the same
folder and are not part of Material Symbols.

Material Symbols are licensed under the Apache License 2.0:
https://github.com/google/material-design-icons/blob/master/LICENSE

The application renders the SVGs as CSS masks so every icon inherits the
semantic color of its context (`currentColor`).

`media-microphone.svg`: Material Symbols Rounded, `mic`, 24 px, from
https://github.com/google/material-design-icons/blob/master/symbols/web/mic/materialsymbolsrounded/mic_24px.svg
